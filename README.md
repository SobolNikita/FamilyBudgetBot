# Семейный бюджет

Учёт расходов одной семьи: Telegram-бот на естественном языке и веб-панель. Backend — Go и PostgreSQL, frontend — React и TypeScript.

В Telegram участник работает только со своими расходами. Веб-панель и REST API открыты по условию [ТЗ](test-task-expenses.md): любой посетитель может управлять данными всей семьи. Для публичного размещения нужна отдельная защита доступа.

## Возможности

- Добавление, просмотр, изменение и удаление расходов через бота и веб.
- Несколько покупок одним сообщением, уточнения и подтверждение удаления.
- Фильтры по участнику, датам и категории, отчёты и пагинация.
- Выбор отдельных расходов или всех по фильтру для массового удаления.
- Удаление участников и восстановление доступа к боту.
- Адаптивный интерфейс со светлой и тёмной темами.

## Быстрый запуск

Нужны Docker Engine и Docker Compose v2.

1. Скопируйте [.env.example](.env.example) в `.env` и замените `POSTGRES_PASSWORD`.
2. Для бота задайте `BOT_ENABLED=true`, `TELEGRAM_BOT_TOKEN`, `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL` — [подробная настройка](docs/operations.md#telegram-и-llm).
3. Запустите:

```sh
docker compose up --build -d
```

Панель: **http://localhost:8080**. Compose сам соберёт frontend, запустит PostgreSQL и применит миграции.

С `BOT_ENABLED=false` веб работает без внешних ключей. Участники появляются после знакомства с ботом: отправьте ему сообщение, укажите имя и подтвердите его. После действий в боте нажмите «Обновить» в панели.

По умолчанию используются `RUB` и `Europe/Moscow`. Выберите валюту и часовой пояс до первого запуска; смена валюты существующего бюджета требует миграции данных.

```sh
docker compose logs -f app
docker compose down
```

`down` сохраняет БД в Docker volume; `down -v` удаляет её.
